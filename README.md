# calm-slack

A calm skin for Slack — [calm](https://github.com/shakilclark/calm) fitted onto Slack's desktop app.

## Apply

1. **Font** → Atkinson Hyperlegible Next (Preferences → Appearance → Font).
2. **Theme** → Custom theme. Paste a preset's four values below.
3. **macOS accent → Graphite** (System Settings → Appearance). Needed for dark — stops the OS
   injecting blue into focus rings.

## Presets

Order: System navigation · Selected items · Presence · Notifications

```
ink     #1A1A1D  #343438  #8E9099  #EDB489
paper   #E7E1D2  #D2C6AE  #6B6456  #B5612F
```

Ink for dark, paper for light. Clay (`#EDB489` / `#B5612F`) is the only colour — the one calm accent.
