# calm-slack

A calm skin for Slack — [calm](https://github.com/therealshakil/calm) fitted onto Slack's desktop app.

## Apply

1. **Font** → Atkinson Hyperlegible Next (Preferences → Appearance → Font).
2. **Theme** → Custom theme → Import. Paste a preset below.
3. **macOS accent → Graphite** (System Settings → Appearance). Needed for dark — stops the OS
   injecting blue into focus rings.

## Presets

Ink for dark, paper for light. Paste the whole line into Slack's theme Import box.

**ink**

```
#1A1A1D,#262629,#343438,#E9E9EC,#222225,#E9E9EC,#8E9099,#EDB489
```

**paper**

```
#E7E1D2,#DCD3C0,#D2C6AE,#26231E,#DCD3C0,#26231E,#6B6456,#B5612F
```

Clay (`#EDB489` / `#B5612F`) is the only colour — the one calm accent.
